# 제천 지역화폐 광역발급 시뮬레이터

영월·단양·정선 주민에게 제천 지역화폐를 발급하면 제천 상권에 돈이 얼마나 더 들어오는지 계산하는 대시보드입니다.

**바로 보기:** https://jongjunlee12.github.io/jecheon-local-currency-simulator/

## 주요 화면
- **제천 시내 매출순위 보기**: 분류별(음식·소매·학원·병원 등) 월 매출 TOP 5를 표와 지도 라벨로 보여주고, 2019년 1월부터 2026년 8월까지 자동 재생합니다.
- **제천으로 돈이 어디서 오나**: 인근 시군 주민이 제천에서 쓴 돈과 제천시민이 밖에서 쓴 돈의 흐름을 지도에 금액과 함께 표시합니다. 시내를 당기면 건물이 용도별 색과 층수 높이로 나타납니다.
- **이웃 주민은 제천 어디에 돈을 쓰나**: 영월·단양·정선·원주 주민의 업종별 제천 소비를 월별 표로 보여줍니다.
- **지역화폐 광역발급 시뮬레이터**: 대상 시군, 가입률, 캐시백, 소비 증가율, 도비 분담을 바꾸면 추가 유입액과 시 예산을 계산합니다.
- **동네별**: 제천 17개 읍면동의 바깥 손님 비율.

## 데이터
| 자료 | 출처 | 기간 |
|---|---|---|
| 점포 월매출·손님 거주지·소비처 | 오픈업 MyBIZMAP(카드 결제 추정) | 2019-01 ~ 2026-08 |
| 인구이동·전입사유 | 통계청 KOSIS 국내인구이동통계 | 2023 ~ 2025 |
| 건물 외곽·용도·층수 | 국토교통부 브이월드 GIS건물통합정보 | 2026-10-09 |
| 행정동 경계 | 오픈업 행정동 폴리곤 | 2026 |
| 바탕 지도 | OpenStreetMap, CARTO | |

- 2025년 11월은 결측이 많아 제외했습니다.
- 주유소와 물류센터 주소로 잡히는 결제는 역외 소비 계산에서 뺐습니다.
- 건물 높이는 층당 4m로 통일했습니다.
